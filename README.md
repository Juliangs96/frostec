# Frostec Refrigeración

Tienda online de una casa de refrigeración (heladeras, aires, lavarropas y herramientas), hecha con Vite, React y JavaScript.

## Funcionalidades
- Catálogo con búsqueda en tiempo real, filtro por categoría y paginación
- Carrito de compras con Context API
- Registro e inicio de sesión con Firebase Authentication
- Panel de gestión protegido para crear, editar y eliminar productos (Firestore)
- Diseño responsivo con React-Bootstrap y styled-components

## Tecnologías
React, Vite, React Router, Firebase, React-Bootstrap, styled-components, React Icons y React Helmet.

## Cómo correrlo
1. Instalar dependencias: `npm install`
2. Copiar `.env.example` como `.env` y completar los datos de Firebase
3. Iniciar: `npm run dev`
